### 带宽：单线程 10–12MB/s，别拿 400Mbps 当保底

网上有些测评表格写圣何塞三网下载都能跑 400Mbps 以上。这个数字和同一批测评在 FAQ 里的说法对不上——同一篇文章又写“实测拉文件稳定在 10–12MB/s，约 80–100Mbps”。

更可信的口径是这样：单线程 wget 拉 1GB 文件，电信线路平均 10–12MB/s，全程稳定；speedtest 测出来电信下载 85–95Mbps、联通 70–85Mbps、移动 60–75Mbps；想跑更高需要多线程并发或者用 iperf3 对打。1Gbps 是端口速率，不是保底带宽，单线程测不到满速是正常现象。

### 回程路由：163 骨干加 NTT/GTT，不是 CN2

圣何塞的回程走普通 163 骨干网，电信去程对接 NTT，联通和移动走 GTT 这类国际线路。全程基本直连，不绕道，但没有 CN2 GT 或 GIA 优化。

有一份测评写圣何塞电信“直接走 CN2 GIA”，这个说法和另外两份更详细的测评冲突，后者都明确写“不是 CN2”。买之前别把 CN2 当预期，它不是这条线路的卖点。

## 常见问题

**1Gbps 为什么测不到？**

1Gbps 是端口速率，不是保底带宽。单线程 wget 跑 10–12MB/s 是正常水平，想跑更高用多线程或 iperf3 对打。speedtest 单线程测出来的数字也不能代表端口上限。

**电信晚高峰丢包怎么办？**

在 VPS 内开 TCP BBR：`echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf`，然后 `sysctl -p`。对丢包场景下的有效吞吐有改善，但改不了物理路由。根本解法是选圣何塞而不是 DC-02，圣何塞电信晚高峰比 DC-02 稳得多。

**黑五套餐和常规套餐有什么区别？**

黑五套餐是促销期放出的年付特供款，价格比常规月付低很多。机房、虚拟化、控制面板都一样，差别在价格、硬盘流量配比和上架时间。促销库存有限，抢完即止。

**机房选错了能换吗？**

不能。RackNerd 不支持机房迁移，买错只能取消重新下单，取消不退款。下单前必须 ping 测试 IP。

**speedtest 为什么不靠谱？**

speedtest 默认选最近节点，国内测速时容易选到机房本地节点，测出来的是机房到机房的速度，不是你本地到机房的速度。手动指定国内节点，或者直接用 iperf3 对打、wget 拉文件更接近真实体验。
